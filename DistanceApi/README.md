# DistanceApi

DistanceApi — это ASP.NET Core Web API приложение для расчета расстояния в километрах между двумя точками по координатам широты и долготы.

## Описание

Приложение принимает координаты двух точек через query string, рассчитывает расстояние по формуле Haversine и возвращает результат в километрах.

## Технологии

- C#.
- ASP.NET Core Web API.
- .NET 10.
- Swagger / OpenAPI.

## Структура запроса

Для работы с API используются следующие параметры:

- `lat1` — широта первой точки.
- `lon1` — долгота первой точки.
- `lat2` — широта второй точки.
- `lon2` — долгота второй точки.

## Примеры использования

### 1. Swagger UI

Используйте Swagger UI для ручной проверки API в браузере.

Откройте:

```text
https://localhost:7170/swagger
```

Далее:
1. Найдите метод `GET /api/distance`.
2. Нажмите `Try it out`.
3. Введите значения параметров:
   - `lat1 = 55.75`
   - `lon1 = 37.61`
   - `lat2 = 59.93`
   - `lon2 = 30.33`
4. Нажмите `Execute`.
5. Просмотрите ответ сервера.

### 2. HTTP-метод в формате endpoint

Используйте следующий endpoint для передачи координат в строке запроса:

```text
GET /api/distance?lat1=55.75&lon1=37.61&lat2=59.93&lon2=30.33
```

### 3. Полный URL для браузера

Используйте эту ссылку, если хотите открыть API напрямую в браузере:

```text
https://localhost:7170/api/distance?lat1=55.75&lon1=37.61&lat2=59.93&lon2=30.33
```

При обращении по этой ссылке приложение вернет JSON-ответ с расстоянием в километрах.

## Пример ответа

```json
{
  "distanceKm": 633.095
}
```

## Валидация входных данных

Приложение проверяет диапазоны координат:

- широта должна быть в диапазоне от `-90` до `90`;
- долгота должна быть в диапазоне от `-180` до `180`.

Если входные данные невалидны, API возвращает ошибку `400 Bad Request`.

## Запуск проекта

1. Откройте решение в Visual Studio.
2. Убедитесь, что проект `DistanceApi` выбран как startup project.
3. Запустите приложение.
4. Откройте Swagger по адресу:

```text
https://localhost:7170/swagger
```

## Примечание

Если у Вас другой порт, замените `7170` на актуальный порт локального запуска.
